# Vues SQL

Plusieurs vues facilitent la consultation des données et le calcul des KPI.

| Vue | Utilisation |
|---|---|
| `vw_articles_complete` | Vue consolidée article, image, label et prédiction |
| `vw_source_statistics` | Statistiques par source |
| `vw_quality_statistics` | Qualité globale des données |
| `vw_pipeline_statistics` | KPI par exécution |
| `vw_daily_pipeline_statistics` | KPI quotidiens |
| `vw_image_quality_statistics` | Qualité des images |
| `vw_label_distribution` | Distribution des labels |
| `vw_feature_statistics` | Couverture des features |
| `vw_model_prediction_statistics` | Statistiques des modèles |
| `vw_prediction_ground_truth_comparison` | Comparaison prédiction / vérité terrain |
| `vw_recent_etl_errors` | Dernières erreurs ETL |
