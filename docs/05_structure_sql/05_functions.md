# Fonctions et procédures

La base contient plusieurs fonctions utilitaires :

- normalisation de texte ;
- validation d’URL ;
- génération de hash ;
- comptage des mots ;
- calcul du temps de lecture ;
- calcul du ratio d’image ;
- calcul de pourcentages ;
- identification des articles multimodaux.

Des procédures permettent également :

- de clôturer une exécution Airflow ;
- d’enregistrer une métrique ;
- d’enregistrer un log ;
- de créer une version de dataset ;
- de purger les anciens historiques.
